# Migration Architecture

Migration Center supports:
- Patreon/generic CSV import concept;
- validation/error reporting;
- field mapping;
- tier mapping;
- billing interval mapping;
- creator earnings/retail strategy;
- grandfathering;
- migration campaign;
- secure member links;
- conversion tracking;
- recovered MRR estimate;
- unconverted export.

Payment credentials are not migrated. Fans must authorize new ZeroFee subscriptions.
