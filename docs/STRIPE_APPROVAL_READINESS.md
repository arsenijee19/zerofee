# Stripe Approval Readiness

ZeroFee needs Stripe confirmation for:
- content-platform approval;
- Connect account type and dashboard access;
- direct charges;
- connected-account fee responsibility;
- managed loss liability;
- embedded onboarding/balances/payouts;
- live webhooks;
- Stripe Tax;
- permitted creator categories and moderation process;
- Guaranteed Earnings wording and route eligibility.

The prototype does not mark these approvals as confirmed.
