# Design System

## Principles
- Calm financial precision with modern creator-SaaS energy.
- Light surfaces, Electric Blue accents, restrained semantic color.
- Marketing is spacious; creator dashboards are medium density; admin is compact and operational.

## Tokens
- Background: `#F7F9FC`
- Surface: `#FFFFFF`
- Text: `#0B1220`
- Muted: `#647087`
- Border: `#E4E9F2`
- Primary: `#1E63FF`
- Success, warning, danger reserved for meaning.

## Components
- Buttons use clear primary/secondary hierarchy.
- Cards are used for product modules and repeated items, not nested page sections.
- Tables become stacked record rows on phone widths.
- Status chips combine color and text.
- Financial values use tabular numerals and explicit labels.

## Mobile
- Navigation collapses to a sheet.
- Data tables convert to stacked rows.
- Critical financial numbers remain readable.
- Checkout and tier builder stack into single-column task flows.
